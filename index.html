Second Brain Backup

A personal backup application operated by its owner. It uses restic and rclone on the owner's Mac to store encrypted, versioned backups in a dedicated folder in the owner's Google Drive.

The application requests only the Google Drive drive.file permission. It accesses files created by or specifically made available to this application. It does not require access to the owner's entire Drive.

Backup contents and filenames inside the restic repository are encrypted before upload. The repository password is stored separately in macOS Keychain. Snapshots are retained; backup is not a bidirectional synchronization service.

This application is for the owner's personal use and is not offered as a public service. It does not sell data or use backup data for advertising.
