Privacy and data handling

Last updated: 24 October 2026.

Second Brain Backup is a personal backup application operated by its account owner. Its purpose is to preserve encrypted recovery snapshots of the owner's local files in the owner's Google Drive.

Google access

The application requests https://www.googleapis.com/auth/drive.file. This permits reading, creating, updating and deleting files created by or specifically made available to the application. The configured backup retains snapshots and does not perform destructive mirroring, pruning or bidirectional synchronization. Drive capacity information is checked before uploading.

Storage and protection

restic encrypts backup contents, filenames and repository metadata locally before rclone uploads them to a dedicated Drive folder. Google still processes account authorization, the folder name, encrypted object sizes and service request metadata. Google OAuth credentials are stored in an encrypted local rclone configuration; the configuration password and restic password are stored in macOS Keychain. Credentials are not published on this website.

Local capture and restore directories contain readable recovery data on the owner's Mac and have restricted access. Backup health records contain operational status, snapshot identifiers and error summaries. They do not intentionally contain OAuth tokens or repository passwords.

Use, sharing and retention

Backup data is used for the owner's backup and recovery only. It is not sold, used for advertising, or supplied to AI services by this backup application. Google stores encrypted objects as the selected storage provider. Snapshots remain until the owner explicitly decides to delete them. This application is not offered to other users as a hosted service.

Owner control

The owner can revoke this application's access in Google Account connections and can stop the local backup job. Revoking access stops subsequent Drive operations but does not automatically delete existing backups. Existing encrypted snapshots require the repository password to recover. Contact and account control are handled by the owner through the Google Cloud project and account used to configure this personal application.

This static information page contains no application analytics or advertising scripts. Its hosting provider may process normal web request logs under that provider's policies.
